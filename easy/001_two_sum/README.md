# 001 · 两数之和（Two Sum）

- 难度：简单
- 语言：Python 3
- 建议用时：20 分钟

## 题目

给定一个整数列表 `nums` 和一个整数 `target`，找出列表中两个相加等于 `target` 的元素，返回它们的下标。

要求：

- 下标从 `0` 开始。
- 每组输入恰好有一个有效答案。
- 不能重复使用同一个元素，但可以使用两个不同位置上数值相同的元素。
- 返回的两个下标顺序不限。

## 示例

### 示例 1

```text
输入：nums = [2, 7, 11, 15], target = 9
输出：[0, 1]
解释：nums[0] + nums[1] = 2 + 7 = 9。
```

### 示例 2

```text
输入：nums = [3, 2, 4], target = 6
输出：[1, 2]
```

### 示例 3

```text
输入：nums = [3, 3], target = 6
输出：[0, 1]
```

## 输入约束

- `2 <= len(nums) <= 10_000`
- `-10**9 <= nums[i] <= 10**9`
- `-10**9 <= target <= 10**9`
- 保证恰好存在一组满足条件的下标。

## 你的任务

在同目录的 `solution.py` 中实现 `two_sum(nums, target)`，返回包含两个下标的列表。

不需要读取标准输入，也不需要打印结果。
